Event-driven import workflow

Bank file → matched records → application import

  1. 01
    Store the input

    The application stores the bank-transaction input file in S3.

  2. 02
    Queue processing

    An SQS message carries the input reference and triggers AWS Lambda.

  4. 04

  5. 05
    Notify the application

  6. 06
    Import transactions

    The application retrieves the processed output and imports the transactions.

03 · FEB–APR 2026

Finding the right
net-wages match.

A similarity-matching engine that supports payroll reconciliation and reduces manual transaction comparison.

PythonScikit-learnFuzzy matchingLambda
Implementation & workflow ＋
PROCESS OVERVIEW

Similarity-matching workflow

Payroll data → candidate matches → reconciliation

  1. 01
    Prepare the request

    The Laravel application supplies reconciliation data through an S3 JSON input for the Python Lambda workflow.

  2. 02
    Preprocess the data

    Python prepares comparison features and scales numeric values for nearest-neighbor comparison.

  3. 03
    Find similar candidates

    Nearest-neighbor search identifies candidate net-wages matches based on feature similarity.

  4. 04
    Compare text fields

    Fuzzy matching supports comparison of text values that may differ in spelling or formatting.

  5. 05
    Support reconciliation

    Candidate matches help the user compare records and complete reconciliation with less manual searching.

Laravel · Python · Scikit-learn · AWS Lambda · S3

Uses nearest-neighbor similarity and fuzzy matching; it is not a supervised prediction model.
